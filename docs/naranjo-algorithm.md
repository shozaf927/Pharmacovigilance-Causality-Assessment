# Naranjo Algorithm

## Overview
The Naranjo Algorithm is a 10-question questionnaire developed to estimate the probability that an adverse event is related to a drug. Each response contributes a defined number of points. The total score maps to four categories.

## Scoring table
| No. | Question | Yes | No | Do not know |
|---:|---|---:|---:|---:|
| 1 | Are there previous conclusive reports on this reaction? | +1 | 0 | 0 |
| 2 | Did the adverse event appear after the suspected drug was administered? | +2 | -1 | 0 |
| 3 | Did the reaction improve when the drug was discontinued or a specific antagonist was administered? | +1 | 0 | 0 |
| 4 | Did the reaction reappear when the drug was readministered? | +2 | -1 | 0 |
| 5 | Are there alternative causes that could have caused the reaction? | -1 | +2 | 0 |
| 6 | Did the reaction reappear when a placebo was given? | -1 | +1 | 0 |
| 7 | Was the drug detected in blood or other fluids in concentrations known to be toxic? | +1 | 0 | 0 |
| 8 | Was the reaction more severe when the dose was increased or less severe when the dose was decreased? | +1 | 0 | 0 |
| 9 | Did the patient have a similar reaction to the same or similar drugs in any previous exposure? | +1 | 0 | 0 |
| 10 | Was the adverse event confirmed by objective evidence? | +1 | 0 | 0 |

## Interpretation
| Total score | Naranjo category |
|---:|---|
| 9 or greater | Definite |
| 5–8 | Probable |
| 1–4 | Possible |
| 0 or less | Doubtful |

## How to use
1. Confirm that the case contains a suspected drug and a clearly described event.
2. Answer every question using documented evidence.
3. Select "Do not know" when the case does not provide enough information.
4. Show the points awarded for every question.
5. Sum the points and report the category.
6. Explain major limitations and alternative causes.

## Critical cautions
- Do not infer a "Yes" from an undocumented fact.
- The algorithm is a structured aid, not proof of causality.
- Its questions may not fit every clinical context or all types of ADR.
- Rechallenge should never be performed solely to increase a score if it is clinically unsafe.
- The algorithm's category **Definite** must not be relabelled **Certain**. WHO–UMC uses a separate category system.
