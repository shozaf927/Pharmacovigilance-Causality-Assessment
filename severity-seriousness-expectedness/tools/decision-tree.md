# Quick Decision Tree

```text
START: Define the event/reaction and gather the case facts
  |
  +--> SEVERITY: Grade intensity using the required scale
  |       Record clinical evidence and functional impact
  |
  +--> SERIOUSNESS: Does at least one regulatory criterion apply?
  |       - Death?
  |       - Life-threatening at the time?
  |       - Inpatient admission / prolonged admission?
  |       - Persistent or significant disability/incapacity?
  |       - Congenital anomaly/birth defect?
  |       - Other medically important event?
  |             YES --> SERIOUS
  |             NO  --> NON-SERIOUS (if adequate information)
  |             UNKNOWN --> PENDING / FOLLOW-UP
  |
  +--> EXPECTEDNESS: Compare with correct current RSI
  |       - Nature consistent?
  |       - Specificity consistent?
  |       - Severity consistent?
  |             YES --> EXPECTED
  |             NO  --> UNEXPECTED
  |             RSI/details insufficient --> PENDING
  |
  +--> ASSESS CAUSALITY SEPARATELY
  |
  +--> Determine local reporting obligation, clock and recipient
  |
  END: Document rationale, source, version, reviewer and audit trail
```

## Reminder
This is a learning aid, not a validated regulatory decision-support system. Follow current local law, product-specific RSI and organisational SOP.
